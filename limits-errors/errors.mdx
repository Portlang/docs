---
title: "Errors"
---

The HS Ping API uses string code to give more context and recommendations.

| Error Code | Details |
| --- | --- |
| UNAUTHENTICATED | Invalid or inactive API key |
| INVALID\_PARAMETER | Invalid request parameters |
| RATE\_LIMIT\_EXCEEDED | Too many requests. Slow down. |
| INSUFFICIENT\_BALANCE | Your account balance is insufficient. Your subscription may need a moment to activate after your trial credit was used, or you may need to upgrade your plan for higher limits. |
